# Портфолио — Рамазан

Fullstack & AI-разработчик. Сайт-портфолио на **React + Vite + TypeScript + Tailwind CSS**.

## Стек

- React 19
- Vite 8
- TypeScript
- Tailwind CSS 4
- Framer Motion (лёгкие анимации)
- Lucide React (иконки)

## Команды

```bash
npm install
npm run dev      # локальная разработка
npm run build    # production-сборка в dist/
npm run preview  # превью production-сборки
```

## Деплой (GitHub Pages)

Сборка кладётся в `dist/`. Базовый путь: `/my_website/`.

```bash
npm run build
# содержимое dist/ — в ветку gh-pages или через GitHub Actions
```
